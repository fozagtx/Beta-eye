Welcome to See

See simplifies page text locally in Chrome and keeps the original text restorable.

How See Protects Pages

  • Simplification starts from your toolbar action.
  • Original text stays mapped in the page session.
  • Sensitive sites are skipped until you allow them.
  • Rules fallback works when Gemini Nano is unavailable.

Gemini Nano

Chrome controls Prompt API availability, model download, hardware checks, and policy checks. See detects what is available and explains the current state in the popup.
