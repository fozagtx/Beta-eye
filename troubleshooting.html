Troubleshooting Beta-eye

Status Meanings

Ready
Gemini Nano is available locally.
Downloading
Chrome reports that the local model still needs download or setup.
Fallback active
Beta-eye is using deterministic local rules instead of the Prompt API.
Site disabled
This host is disabled in your Beta-eye settings.
Sensitive site skipped
Beta-eye avoids banking, health, government, email, docs editor, and code repository sites by default.

Model Requirements

Prompt API support depends on Chrome version, channel, flags, policy, disk space, memory, and model download state. Beta-eye continues to work in rules fallback mode when those requirements are not met.

Page Restore

Use Restore original from the popup. Restore state is held for the current page session, so refreshing the tab returns the site to its own original content too.
