Troubleshooting Redacto

Status Meanings

Ready
Redacto is ready to scan locally.
Downloading
Redacto is scanning the page for confidential values.
Fallback active
Redacto uses deterministic local detection on every device.
Site disabled
This host is disabled in your Redacto settings.
Sensitive site skipped
Redacto avoids banking, health, government, email, docs editor, and code repository sites by default.

Detection Limits

Detection covers common emails, phones, payment cards, government identifiers, tokens, and API keys. It cannot identify every confidential value, so always review the result.

Page Restore

Use Restore original from the popup. Restore state is held for the current page session, so refreshing the tab returns the site to its own original content too.
